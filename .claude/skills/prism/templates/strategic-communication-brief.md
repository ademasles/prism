# Template — Strategic Communication Brief

The core artifact of PRISM's thinking. Fill every field. Keep each to 1–3 tight lines. Mark anything unconfirmed as an assumption.

## Instructions
- Write the **inferred true objective** as a verb + specific audience + ask (never a topic).
- If a field is unknown, write `ASSUMPTION: …` rather than leaving it blank or inventing a fact.
- This brief drives everything downstream — the transformation map, the recommendation, the draft, the review.

## Structure

```
## Strategic Communication Brief

**Raw request:** <what the user literally asked for, incl. the format they named>

**Inferred true objective:** <verb + audience + specific outcome/ask>

**Communication mode:** <education | alignment | decision support | persuasion | escalation | enablement | discovery> (+ secondary if real)

**Success definition:** <what observably happens if this works — the decision made, the shift achieved>

**Audience:** <named roles; who actually decides>

**Current audience state:** <what they believe / fear / ignore today>

**Desired future audience state:** <what they must believe, feel, be ready to do>

**Decision / action required:** <specific ask: owner, size, timing>

**Likely objections:** <the real reasons for no / delay / disengagement>

**Evidence required:** <proof this audience will trust, per key claim>

**Evidence gaps:** <what proof we don't yet have — named honestly>

**Communication strategy:** <the spine: what leads, sequence, how objections are pre-empted, what moves them current → desired>

**Recommended artifact:** <primary (+ secondary), one line why it beats the default>

**Assumptions:** <every gap left by unanswered questions, labelled>

**Open questions:** <unknowns that would most change the outcome>
```
