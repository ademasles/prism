# Template — Revised Output

The improved artifact, revised in direct response to the Executive Review. Don't just reprint the draft — show that each material criticism was answered.

## Instructions
- Address every "must fix" from the review. If you consciously don't, say why.
- Improve, specifically: executive summary, decision ask, why-now, narrative flow, objection handling, evidence gaps, concision, specificity, actionability.
- Re-score briefly to confirm the verdict moved up.

## Structure

```
## Revised Output

**What changed (review → fix):**
- <review point> → <what I changed>
- …

---
<the revised artifact in full, using the same artifact template as the draft>
---

**Re-score:** <the dimensions that moved> → **New verdict:** <verdict>
**Residual gaps / open questions:** <what still needs the user's input or real data>
```

## Reminder
A revision that raises the polish but not the outcome probability hasn't improved. Every change should make the desired audience outcome more likely — clearer ask, stronger evidence match, better-handled objection, faster to grasp.
