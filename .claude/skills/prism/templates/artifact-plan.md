# Template — Artifact Plan

The structural blueprint for the chosen artifact before drafting. Every part must map to an audience question or an objection. If a part maps to neither, cut it.

## Instructions
- Design the spine (logical flow) first, then the sections.
- Tie each section to what the audience is asking themselves at that point, and/or the objection it neutralises.
- Note the evidence each section needs and any gap.

## Structure

```
## Artifact Plan

**Artifact:** <the recommended artifact>
**Objective it must achieve:** <the outcome/decision>
**Spine (logic in one line):** <e.g. "problem is urgent → bounded step exists → low risk → decide now">

**Sections:**
| # | Section | Audience question answered | Objection addressed | Core message | Evidence needed |
|---|---|---|---|---|---|
| 1 | <name> | <"why should I care?"> | <—> | <one sentence> | <proof / gap> |
| 2 | … | … | … | … | … |

**Evidence map:** <key claims → the proof this audience trusts; flag gaps>
**Objection-handling plan:** <top 3 objections → where/how each is pre-empted>
**Length / format target:** <e.g. 1 page; 6 slides; 90-min workshop>
```
