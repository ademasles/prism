# Template — Audience Transformation Map

Makes the state change explicit and testable. This is where PRISM earns its name: from a vague request to a concrete map of how specific people must change.

## Instructions
- Anchor on current → desired state; everything else is the mechanism.
- Frame belief shifts as stop → start pairs.
- Include trust shifts only if trust is a live blocker.
- The final table forces you to justify *why each shift matters* — cut any shift that doesn't tie to the outcome.

## Structure

```
## Audience Transformation Map

**Audience:** <named roles; the decider>

**Current state:** <what they believe / feel / do today>

**Desired future state:** <what they must believe / feel / be ready to do>

**Belief shifts:**
- Stop believing: <…> → Start believing: <…>
- Stop believing: <…> → Start believing: <…>

**Confidence shifts:** <from "understands X" → "confident enough to do Y"; what closes the gap>

**Trust shifts (if relevant):** <whose credibility must rise, and how>

**Action required:** <the specific decision/action, owner, timing>

**Risk if no change happens:** <cost of the audience staying in the current state>
```
